# 简智 · 智能简历工作台

一个纯前端智能简历编辑器，帮助求职者实时诊断简历质量、匹配岗位关键词、输出专业排版。所有数据保存在浏览器本地存储，无需后端。

## 功能特性

- **实时编辑与自动保存**：左侧编辑面板，右侧实时预览，修改后自动落盘。
- **简历质量诊断**：基于 bullet 优化建议，给出表达改进提示。
- **岗位匹配分析**：输入目标岗位描述，分析简历关键词匹配度。
- **专业模板排版**：支持现代专业 / 经典简约两种模板一键切换。
- **本地数据管理**：自动保存到浏览器 `localStorage`，支持导出/导入 JSON 备份。
- **撤销重做**：最多保留 30 步历史，误操作可一键回退。

## 运行与构建

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 输出 dist/ 静态文件
npm run preview  # 本地预览构建产物
```

## 使用说明

1. 打开页面后，左侧编辑简历各模块（个人信息、工作经历、项目经验、教育背景等）。
2. 右侧实时预览最终效果。
3. 点击「诊断」查看简历优化建议。
4. 点击「匹配岗位」粘贴 JD，查看关键词匹配情况。
5. 完成后可导出 JSON 备份，或直接在浏览器中打印/保存 PDF。
